# OSS Buddy First PR Task Finder

This example simulates the core concept of "OSS Buddy" by identifying small, manageable tasks within a hypothetical project's issue list. It filters tasks based on criteria like "easy" difficulty and labels such as "documentation" or "bug," making them suitable for a developer's first open-source Pull Request.

## Language

`python`

## How to Run

Save the code as `main.py` and run it from your terminal using `python main.py`.
